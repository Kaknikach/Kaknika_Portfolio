# Photos go here

Drop an image at one of these paths (same name, .jpg) and it appears on the site.
Until then, a soft green/pink placeholder shows instead.

| File | Where it shows |
|---|---|
| `profile.jpg` | Homepage hero (portrait, about 4:5) |
| `projects/focus-quest.jpg` | Projects → Focus Quest |
| `projects/kirishield.jpg` | Projects → KiriShield |
| `projects/twenty1.jpg` | Projects → Twenty1 Studio |
| `projects/techfoundation.jpg` | Projects → TechFoundation |
| `leadership/voi.jpg` | Leadership → Voices of Insight |
| `leadership/msm.jpg` | Leadership → Math & Science Mystery |
| `leadership/ted-ed.jpg` | Leadership → TED-Ed Club |
| `beyond/running.jpg` | Beyond → Running |
| `beyond/content.jpg` | Beyond → Content creation |

Tip: keep each photo under ~500 KB so the site loads fast (export at ~1600px wide).
